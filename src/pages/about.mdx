# About

## The project

Voltaire is a multiphysics solver for electrochemical cells, built around one idea: write
the residual once, differentiate it once, and let the same Jacobian drive time stepping,
impedance, and design sensitivities. The [numerics page](/Electrochemical-Cell-Simulator/numerics/)
walks through that spine, and the [physics section](/Electrochemical-Cell-Simulator/physics/)
derives each model it carries.

What exists today is this site and its [browser demos](/Electrochemical-Cell-Simulator/demos/) —
a self-contained in-browser solver, written in TypeScript and computed on your own machine.
The Python solver package is planned and not yet written; the
[roadmap](/Electrochemical-Cell-Simulator/roadmap/) is the status of record, and the
[validation page](/Electrochemical-Cell-Simulator/validation/) is where the claims get
checked against analytic results while you watch.

## Why

Simulations are what got me hooked on this project specifically — there's something clarifying
about watching a system actually behave, instead of just deriving how it should on paper. I
wanted to build something that made electrochemistry feel less like a black box, for myself
and for anyone curious enough to drag a slider and watch what happens.

## How it is built

The site is a static [Astro](https://astro.build) build with no client framework: every
demo is hand-written TypeScript talking to a canvas or a WebGL2 context, and the numerical
kernels are covered by unit tests that run on every push. Nothing on the site is a
prerecorded animation, and no figure is an artist's impression — the
[gallery](/Electrochemical-Cell-Simulator/gallery/) images are generated at build time by
the same code the demos run.

The honesty rules the site follows are deliberate and worth stating plainly: a number is
only presented as measured if it was computed live in your browser or by exact analytics,
anything unbuilt carries a status badge saying so, and benchmarks that have not been run
are labelled *not yet run* rather than quietly omitted.
