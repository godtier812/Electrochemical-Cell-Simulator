# Roadmap

Shipped today: this website and its five in-browser demos, which implement the project's actual numerics in TypeScript — Scharfetter–Gummel fluxes with damped Newton for Poisson–Nernst–Planck, Tikhonov-regularised NNLS for DRT, RSA microstructure generation with Laplace tortuosity, an explicit phase-field dendrite solver, and Butler–Volmer kinetics — backed by 22 unit tests on the numerical kernels. In development: the Python solver package, which ports the same numerics onto an autodiff core so that one Jacobian $J = \partial R/\partial u$ serves time stepping, impedance, and design sensitivities.

Every item below carries a status badge. "Shipped" means you can run it in your browser right now. "In progress" means code exists and is being ported or extended. "Planned" and "research" mean exactly what they say: not built yet.

## The five-day MVP sprint

The Python MVP is scoped as a five-day sprint. The order is not decoration — each day consumes the residuals and Jacobian structure the previous day built.

1. **Day 1 — 1D transport core.** The Poisson–Nernst–Planck system in one dimension: Scharfetter–Gummel exponential-fitting fluxes on a finite-volume grid, solved implicitly with a damped Newton iteration. These numerics already run in the [double-layer demo](/Electrochemical-Cell-Simulator/demos/#demo-double-layer); the Python port onto the autodiff core is in progress.
   <StatusBadge status="shipped" label="browser demo" /> <StatusBadge status="in-progress" label="Python port" />

2. **Day 2 — Butler–Volmer coupling and thermal block.** Butler–Volmer kinetics as the boundary condition linking electrode potential to interfacial flux, plus an energy balance so overpotential heat feeds back into temperature-dependent parameters. The kinetics are live in the [Butler–Volmer demo](/Electrochemical-Cell-Simulator/demos/#demo-butler-volmer); the thermal block is in progress.
   <StatusBadge status="shipped" label="kinetics in browser" /> <StatusBadge status="in-progress" label="thermal block" />

3. **Day 3 — frequency-domain EIS and DRT.** Impedance spectra and their inversion to a distribution of relaxation times by Tikhonov-regularised NNLS run in the [impedance demo](/Electrochemical-Cell-Simulator/demos/#demo-impedance). The full Jacobian-based path — solving $(i\omega M - J)\hat{u} = \hat{b}$ around a Newton-converged operating point — needs the autodiff core and ships with the Python package.
   <StatusBadge status="shipped" label="browser demo" /> <StatusBadge status="in-progress" label="Jacobian EIS" />

4. **Day 4 — phase-field dendrites and microstructure.** Explicit phase-field dendrite growth (the animation on the landing page is the solver, not a video) and RSA-packed electrode microstructures whose tortuosity comes from a Laplace solve. Both run in the browser: [dendrite demo](/Electrochemical-Cell-Simulator/demos/#demo-dendrite), [microstructure demo](/Electrochemical-Cell-Simulator/demos/#demo-microstructure).
   <StatusBadge status="shipped" label="browser demo" />

5. **Day 5 — validation suite and docs.** Gouy–Chapman, Cottrell, and method-of-manufactured-solutions checks run live on the [validation page](/Electrochemical-Cell-Simulator/validation/), comparing the browser solvers against exact analytic results. The PyBaMM P2D comparison has not yet been run and will not be quoted until it has.
   <StatusBadge status="shipped" label="analytic checks" /> <StatusBadge status="planned" label="PyBaMM P2D: not yet run" />

## The longer arc

Past the MVP, the plan follows the same spine — one residual, one Jacobian — into harder territory. None of this is built.

- **Concentrated-solution transport** <StatusBadge status="planned" /> — replace the dilute Nernst–Planck closure with concentration-dependent transport properties for battery electrolytes where the dilute assumption breaks down.
- **Chemo-mechanics and the fracture–SEI loop** <StatusBadge status="research" /> — couple intercalation stress to particle fracture and SEI growth on freshly exposed surface, closing the capacity-fade feedback loop.
- **Gas evolution for electrolysers** <StatusBadge status="planned" /> — bubble coverage and gas-phase transport at gas-evolving electrodes, and their effect on active area and ohmic drop.
- **PINN and DeepONet surrogates with ONNX export** <StatusBadge status="research" /> — train neural surrogates on solver trajectories and export them to ONNX so fast inference does not require the full solver.
- **Bayesian inverse design** <StatusBadge status="research" /> — infer cell parameters from measured impedance and cycling data with full posterior distributions, using adjoint gradients from $J^\top \lambda = -\partial Q/\partial u$.
- **Uncertainty quantification** <StatusBadge status="planned" /> — Sobol sensitivity indices and polynomial-chaos expansions to propagate parameter uncertainty through cell-level predictions.
