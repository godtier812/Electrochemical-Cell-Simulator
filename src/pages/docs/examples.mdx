## 1C discharge of a graphite–NMC cell

The canonical first simulation: discharge a full cell at 1C and plot voltage against
delivered capacity.

```python
import voltaire as vt

cell = vt.Cell.from_preset("graphite-nmc-1d")   # geometry, OCV curves, transport
                                                # and kinetic parameters

result = cell.discharge(c_rate=1.0, cutoff_voltage=3.0)   # V

ax = result.plot("voltage")                     # V against delivered capacity
ax.figure.savefig("discharge_1c.png")
```

The preset bundles a porous-electrode description of both electrodes: concentrated-solution
[transport](/Electrochemical-Cell-Simulator/physics/transport/) in the electrolyte, solid
diffusion in the particles, and Butler–Volmer
[kinetics](/Electrochemical-Cell-Simulator/physics/kinetics/) at each interface.
`discharge()` integrates the semi-discrete system implicitly, solving each step with the damped Newton
method described on the [numerics page](/Electrochemical-Cell-Simulator/numerics/).

Expect three regions in the curve. At the start, the voltage steps down from open circuit by
the ohmic and charge-transfer overpotentials. The middle is a sloping plateau that tracks the
difference of the two open-circuit potentials, offset below it by the rate-dependent
polarisation. Near the end, the curve bends down sharply as solid-phase diffusion stops
keeping up with the surface reaction and concentration polarisation takes over. Two sanity
checks: rerun at C/10 and the whole curve should move up toward the open-circuit difference,
and the capacity delivered at 1C should come out below the nominal (low-rate) capacity.

## Double-layer study with PNP

Switching the transport model to `pnp` drops the electroneutrality assumption, which is what
lets the solver resolve the diffuse double layer at all. This example sweeps the bulk
concentration and checks the screening length against theory.

```python
import voltaire as vt

steady = {}
for c0 in [10.0, 100.0, 1000.0]:               # mol/m³ = 0.01, 0.1, 1 M
    cell = vt.Cell.from_config({
        "preset": "li-symmetric",              # bundled symmetric cell as the base
        "geometry": {"gap": 50e-9},            # nm-scale gap: the domain is the double layer
        "electrolyte": {"c0": c0},             # bulk concentration of the 1:1 salt
        "transport": {"model": "pnp"},         # Poisson–Nernst–Planck, no electroneutrality
        "mesh": {"grading": "geometric", "min_debye_points": 10},
    })
    # A 10 mV hold, integrated to its steady state.
    steady[c0] = cell.cycle("hold at 0.010 V for 1 s", n_cycles=1)
```

The 10 mV hold keeps the electrode in the linear (Debye–Hückel) regime, where the potential
decays from the wall as a single exponential with decay constant $\lambda_D$:

<Equation id="eq-debye" latex="\lambda_D = \sqrt{\frac{\varepsilon R T}{2 F^2 c_0}}" caption="Debye length of a symmetric 1:1 electrolyte. The rule of thumb — 0.304 nm divided by the square root of the molar ionic strength — follows directly." />

<SymbolTable rows={[
  { s: '\\lambda_D', meaning: 'Debye screening length', units: 'm', typical: '3e-10 – 1e-8' },
  { s: '\\varepsilon', meaning: 'solvent permittivity (relative times vacuum)', units: 'F/m', typical: '6.9e-10 (water, 298 K)' },
  { s: 'R', meaning: 'gas constant', units: 'J/(mol·K)', typical: '8.314' },
  { s: 'T', meaning: 'temperature', units: 'K', typical: '298' },
  { s: 'F', meaning: 'Faraday constant', units: 'C/mol', typical: '96485' },
  { s: 'c_0', meaning: 'bulk concentration of the 1:1 salt', units: 'mol/m³', typical: '10 – 1000' },
]} caption="Symbols in the Debye length" />

### Checking the scaling

```python
import numpy as np

eps, R, T, F = 6.94e-10, 8.314, 298.15, 96485.0
for c0, result in steady.items():
    result.plot("profiles")                    # phi(x): exponential decay at each wall
    lam_theory = np.sqrt(eps * R * T / (2 * F**2 * c0))
    print(f"{c0/1000:.2f} M: analytic Debye length {lam_theory*1e9:.3f} nm")
```

In water at 298 K the analytic values are about 0.30 nm at 1 M and 0.96 nm at 0.1 M, and the
sweep as a whole should reproduce the inverse-square-root scaling of the 0.304 nm rule of
thumb. Read the screening length off each potential profile as the distance over which
$\varphi$ falls by a factor of $e$ from its wall value — the
[double-layer demo](/Electrochemical-Cell-Simulator/demos/#demo-double-layer) performs the
same exponential fit automatically. If the lengths read off the profiles drift from the
analytic ones at high concentration, the first
suspect is the mesh: the grading near the electrode must place several cells inside one
$\lambda_D$, which at 1 M means sub-ångström resolution at the wall. The
Scharfetter–Gummel discretisation that keeps this stable is derived on the
[transport page](/Electrochemical-Cell-Simulator/physics/transport/).

## EIS and DRT from the Jacobian

Voltaire computes impedance spectra without time stepping. After solving the steady state,
each frequency is one complex linear solve against the same Jacobian that Newton already
assembled:

<Equation id="eq-eis-example" latex="\left(i\omega M - J\right)\hat{u} = \hat{b}" caption="The frequency-domain EIS system. One sparse complex solve per frequency; J is the Newton Jacobian at the operating point." />

<SymbolTable rows={[
  { s: 'M', meaning: 'mass matrix; zero rows on algebraic equations', units: 'problem-dependent' },
  { s: 'J', meaning: 'autodiff Jacobian at the operating point', units: 'problem-dependent' },
  { s: '\\omega', meaning: 'angular frequency of the perturbation', units: 'rad/s', typical: '6e-2 – 6e5' },
  { s: '\\hat{u}', meaning: 'complex amplitude of the state perturbation', units: 'mixed' },
  { s: '\\hat{b}', meaning: 'complex forcing vector (applied current)', units: 'mixed' },
]} caption="Symbols in the frequency-domain EIS system" />

```python
import voltaire as vt

cell = vt.Cell.from_preset("graphite-nmc-1d")

# Steady state by damped Newton, then 50 log-spaced solves of (iωM − J)û = b̂
# between 10 mHz and 100 kHz.
spec = cell.impedance(f_min=0.01, f_max=1e5, n=50)

drt = spec.drt(lambda_reg=1e-2)   # Tikhonov-NNLS inversion

spec.plot("nyquist")              # equal axis scaling, −Im Z upward
drt.plot()
```

### Reading the result

The Nyquist plot should show a high-frequency real intercept (the ohmic resistance), one or
more arcs from charge transfer at the two electrodes, and a low-frequency 45° tail that rolls
over as the finite-length diffusion limit is reached. Where arcs overlap into a single
depressed bump, the DRT separates them by timescale: charge-transfer peaks sit at short
relaxation times, microseconds to milliseconds, while diffusion contributes peaks at
milliseconds to seconds and beyond. Do not trust a peak at a single regularisation strength —
sweep `lambda_reg` over a decade or two and keep only the peaks that stay put. The inversion, its
failure modes, and the analytic Warburg checks are on the
[impedance page](/Electrochemical-Cell-Simulator/physics/impedance/).

## SEI ageing over 500 cycles

Attach an SEI growth model to the negative electrode and cycle the cell, tracking
discharge capacity cycle by cycle.

```python
import numpy as np
import voltaire as vt

cell = vt.Cell.from_config({
    "preset": "graphite-nmc-1d",               # bundled full cell as the base
    "degradation": {"sei_model": "kinetic-diffusion",
                    "sei_kappa": 5e-6},        # S/m — film conductivity, no default
})

result = cell.cycle(
    "1C charge to 4.2 V hold until C/50, rest 600 s, "
    "1C discharge to 3.0 V, rest 600 s",
    n_cycles=500,
)

df = result.to_pandas()                        # scalar traces: t, V, I, T, capacity
# Plain pandas from here: number the cycles at each switch into discharge
# (positive current), then integrate current over each discharge step.
df["cycle"] = ((df["I"] > 0) & (df["I"].shift(fill_value=0.0) <= 0)).cumsum()
fade = (df[df["I"] > 0]
        .groupby("cycle")
        .apply(lambda step: np.trapezoid(step["I"], step["t"]) / 3600.0))  # Ah/m²
fade.plot(xlabel="cycle number", ylabel="discharge capacity (Ah/m²)")
```

The SEI reaction consumes cyclable lithium and thickens an insulating film, so capacity fades
while $R_{\mathrm{SEI}}$ grows in proportion to the film thickness — the film state itself
stays on the `Result` as field arrays, alongside the scalar traces exported above. Both
effects should show two regimes. Early on, the film is thin and the interfacial reaction is the
bottleneck: growth per cycle is roughly constant and the fade looks linear. As the film
thickens, solvent transport through it becomes limiting, growth slows in inverse proportion
to thickness, and the fade flattens into the familiar square-root-of-time shape. If your
capacity-versus-cycle plot is a straight line for all 500 cycles, the model never left the
kinetics-limited regime — lower the diffusivity through the film or cycle longer. The growth
law and its two limits are derived on the
[degradation page](/Electrochemical-Cell-Simulator/physics/degradation/).

## Inverse design with Bayesian optimisation

<StatusBadge status="planned" label="design module" /> A teaser for the design loop: find the
cathode porosity and thickness that maximise energy delivered at fixed power.

```python
import voltaire as vt

cell = vt.Cell.from_preset("graphite-nmc-1d")

study = vt.design.bayes_opt(
    cell,
    objective="energy_at_power",     # named scalar: energy delivered by a
                                     # constant-power discharge at rated power
    bounds={
        "cathode.porosity":  (0.20, 0.50),
        "cathode.thickness": (40e-6, 120e-6),   # m
    },
    n_iter=40,                       # simulation budget: full discharges
    gradients=True,                  # dQ/dp by adjoint, from the shared Jacobian
)

print(study.best_point, study.best_value)
```

The objective has an interior optimum because the two parameters pull against each other: a
thick, dense electrode stores more lithium but starves on electrolyte transport at power,
while a thin, porous one discharges efficiently with little to discharge. Each evaluation of
the objective is a full constant-power discharge, so evaluations are expensive — which is
exactly the regime Bayesian optimisation is built for. A Gaussian-process surrogate models
the objective over the design space, and the expected-improvement acquisition picks the next
design to simulate.

The adjoint solve makes each evaluation worth more. Solving
$J^{\mathsf{T}}\lambda = -\partial Q/\partial \mathbf{u}$ — the third consumer of the one
autodiff Jacobian, alongside Newton and EIS — yields the full gradient $dQ/dp$ for the cost
of roughly one extra linear solve, independent of how many parameters $p$ holds. Feeding
those gradients to the GP as derivative observations sharpens the surrogate where it has
actually looked. The shared-Jacobian architecture is described on the
[numerics page](/Electrochemical-Cell-Simulator/numerics/).
