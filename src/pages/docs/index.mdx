## Status

<StatusBadge status="planned" label="Python package: planned" /> <StatusBadge status="planned" label="voltaire-echem on PyPI" />

The Voltaire Python package is planned and is not on PyPI. There is nothing to `pip install` today, and any package you find under a similar name is not this project. The planned distribution name is `voltaire-echem`; when it ships, this page becomes a one-line install.

What is real and running right now is this site and its demos. They are not videos or mock-ups, and they are not a front end over a backend: they are a self-contained **in-browser solver** — TypeScript implementations of the governing equations, computed on your own machine, at demo scale in one or two dimensions on fixed configurations rather than as a general-purpose package.

## Run the numerics today, nothing to install

The [demos page](/Electrochemical-Cell-Simulator/demos/) runs these models entirely in your browser. The planned Python package is being built around the same equations, but nothing on that side exists yet:

## Install from source

{!REPO_PUBLIC && <StatusBadge status="in-progress" label="repository not yet public" />}

<RepoNote kind="installIntro" />

### Requirements

- Python 3.11 or newer
- git

### Steps

```bash
git clone https://github.com/godtier812/Electrochemical-Cell-Simulator
cd Electrochemical-Cell-Simulator
python3.11 -m venv .venv
source .venv/bin/activate
pip install -e .
```

The editable flag (`-e`) makes edits to the source take effect without reinstalling, which matters while the API is still moving. On Windows, activate with `.venv\Scripts\activate` instead of the `source` line.

### Dependencies

The core install pulls in three packages:

- `numpy` — arrays and linear algebra
- `scipy` — sparse matrices and solvers
- `matplotlib` — the `.plot()` methods on results

### Optional: JAX

JAX is optional. It is what makes the architecture's central object — the Jacobian $J = \partial R / \partial u$ of the full residual — come from automatic differentiation rather than hand-written derivatives, and it backs the ML layer. The same Jacobian is consumed three ways: damped Newton time stepping, frequency-domain impedance via $(i\omega M - J)\hat{u} = \hat{b}$, and adjoint design sensitivities via $J^{\top}\lambda = -\partial Q / \partial u$. Without JAX the core solver still installs and runs on NumPy and SciPy.

```bash
pip install jax
```

That installs the CPU build; for GPU builds, follow the install matrix in the JAX documentation, since the right wheel depends on your hardware.
