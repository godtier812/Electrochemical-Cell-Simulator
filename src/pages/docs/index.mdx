## What runs today

Everything on this site that computes does so in your browser: TypeScript implementations of
the governing equations, on fixed configurations at demo scale, with no server behind them.
They are covered by unit tests, and the [validation page](/Electrochemical-Cell-Simulator/validation/)
reruns the analytic checks every time it loads. There is nothing to install.

## The Python package

<StatusBadge status="planned" label="voltaire-echem: planned" />

The Python solver is planned and not written, and it is not on PyPI. There is nothing to
`pip install`, and any package you find under a similar name is not this project. Its intended
interface is published on the [design page](/Electrochemical-Cell-Simulator/docs/python/) so
that it can be criticised before it hardens, and its progress is tracked on the
[roadmap](/Electrochemical-Cell-Simulator/roadmap/).
